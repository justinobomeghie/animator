# Problem 14 video storyboard (about 90 seconds)

1. **0:00–0:12 — Studio overview.** Show the editor, drawing chooser, square canvas, and shape and speed controls.
2. **0:12–0:35 — Original sketch.** Create a named drawing such as “Orbit Study” and write a recursive line pattern in the editor. Show the live preview update as the code changes.
3. **0:35–0:55 — Extension controls.** Move the shape slider to change the pattern, use slow and fast playback, reverse the speed briefly, then reset and replay it.
4. **0:55–1:15 — Library workflow.** Switch to a supplied example and back to “Orbit Study.” Refresh the page and show that the custom drawing and selection return.
5. **1:15–1:30 — Resilience and close.** Briefly introduce a syntax error to show the visible message while the editor text remains, then undo it and end on the completed animation.

Record the video, upload it to Google Drive, and set sharing to “Anyone with the link” before adding the resulting URL to `video_url` in `src/app.gleam`.
